# 共享剪贴-卢（ClipDitto）

仿 Windows 软件 Ditto 的安卓本地剪贴板记录工具：悬浮球 + 剪贴板自动记录 + 无障碍点击粘贴 + 局域网/云端中继多设备同步 + 局域网文件互传。

PC 端姊妹项目：[pc-lscopy（copy-pc）](https://github.com/duangdangding/pc-lscopy)，可与本 App 互相同步、互传文件。

## 功能

1. **悬浮球**：开启服务后屏幕边缘出现球形悬浮窗（可拖动），单击展开/收起剪贴板记录面板。面板不抢焦点、可拖动调位置、可拖手柄调大小，位置尺寸自动记忆；面板内支持模糊搜索、暂停/恢复监听。
2. **自动记录**：复制文字、图片、视频、音频、文件（含截图、录屏文件）自动入库，媒体内容复制到应用私有目录长期保存。支持 Shizuku 免打扰读取（见下文「技术要点」）。
3. **点击粘贴**：光标在输入框中时，点击悬浮面板中的文字记录，自动粘贴到输入框（依赖无障碍服务），可连续粘贴多条；图片/文件/视频则放回系统剪贴板供手动粘贴。
4. **记录管理**：模糊搜索（支持子序列匹配，"剪板" 也能命中 "剪贴板"）、收藏置顶（★）、查看详情、单条删除；可设置记录数量上限（100/300/500/1000/自定义），超出自动清理最旧的非收藏记录。
5. **口令识别**：自动识别电商/短视频分享口令（抖音/快手/拼多多/京东/淘宝等），记录旁出现「打开 XX App」按钮一键跳转；内容带链接时提供浏览器打开入口。
6. **按时间段删除**：最近 1 小时 / 今天 / 最近 7 天 / 最近 30 天 / 自定义日期范围 / 全部清空，删除时同步清理媒体文件；含收藏记录时二次确认是否保留。
7. **备份与导入**：导出为 zip（`clips.json` + 媒体文件），导入时自动合并记录并还原媒体，不覆盖现有数据。
8. **局域网多设备同步**：配对码配对后可在设备间互相同步剪贴板记录；手动同步可选范围（最近 N 条 / 某一天 / 全部），也可开启自动增量同步（默认 30 秒一轮）。可配置同步类型（文字/图片/影视/其他）、文件大小上限（默认 20M）、存储目录（默认 `Download/ClipDitto`）、加密传输（ECDH 临时密钥 + AES/GCM，默认关闭）。离线设备可手动从列表移除，也可单独删除某设备同步来的记录。
9. **云端中继同步**：自建中继服务器（WebSocket over TLS 长连接）作为局域网之外的第二条同步通道，两条通道同时激活、各走各的，离开局域网（切蜂窝网络）也能与 PC 互相同步。挑战-响应 HMAC 鉴权（密钥不上线），离线期间条目由服务器暂存、重连后按游标补拉；可填分组密钥开启端到端加密（HKDF + AES-256-GCM，服务器只见密文）；图片默认仅局域网，可开关放行（≤4MB）。设计文档见 `docs/android-relay-sync-design.md`。
10. **文件共享**：局域网内免配对互传任意文件，与同步功能相互独立。自动发现在线设备（含 PC 端 copy-pc），也可手动输入 IP 发送；接收时可弹窗确认或开启自动接收；传送记录支持搜索、打开文件、批量删除。
11. **应用内更新**：关于页显示当前版本，可检查 GitHub Releases 新版本；发现新版本不弹确认框、不展示更新日志，点「立即更新」直接下载（带进度、可取消），SHA-256 校验通过后调起系统安装器。主页检测到新版本时只弹一条轻提示。

## 构建

用 Android Studio（Hedgehog 及以上）打开本目录，等待 Gradle Sync 完成后运行即可。

- AGP 8.5.0 / Kotlin 1.9.24 / Gradle 8.7 / JDK 17
- compileSdk 34，minSdk 26，targetSdk 34
- 数据库：Room 2.6.1（KSP）

## 发版

```powershell
.\release.ps1 -Version 4.5 -Message "改动说明"
```

脚本自动完成：递增 versionCode → 本地编译验证（`-SkipBuild` 可跳过）→ 提交 → 打 tag → 推送。推送 tag 后 GitHub Actions 自动用签名密钥库打包 release APK，生成 `lscopy_v<tag>.apk` 与 SHA-256 校验文件并上传到 Releases。

## 使用步骤

1. 安装后打开 App，点击「开启监听+悬浮球」，按提示授予**悬浮窗权限**（显示在其他应用上层）。
2. 点击「开启无障碍粘贴」，在系统无障碍设置中找到「共享剪贴-卢」并开启——这是"点击记录直接粘贴到输入框"的前提。
3. （可选）授权 Shizuku，彻底免打扰读取剪贴板。
4. 之后在任何 App 中复制内容都会自动记录；点击悬浮球 → 点击记录 → 内容粘贴到当前输入框。

## 技术要点与已知限制

- **Android 10+ 后台剪贴板限制**：系统不允许后台 App 读剪贴板。默认方案：检测到剪贴板变化时，临时添加一个 1px 全透明、可获取焦点的悬浮窗，夺取焦点读取后立刻移除——需要悬浮窗权限常开。
- **Shizuku 免打扰读取**：授权 Shizuku 后，读取动作转发到 shell 进程执行，完全不抢焦点、无任何界面副作用（输入法闪烁、生物识别打断等问题消失）；连续失败自动熔断回退焦点读取。每次重启手机后需重新激活 Shizuku。
- **文字粘贴**：先把内容写入系统剪贴板，再由无障碍服务对当前聚焦的可编辑节点执行 `ACTION_PASTE`。未开启无障碍时自动降级为"复制到剪贴板，手动长按粘贴"。
- **媒体粘贴**：通过 `FileProvider` 把私有目录文件以 Uri 形式放回系统剪贴板；目标 App 是否支持粘贴该类型由目标 App 决定。
- **截图/录屏**：系统截图、录屏本质上是图片/视频文件，复制它们（或在文件管理器中复制）即按媒体类型入库。
- 开机自启：授予开机权限后，重启手机自动恢复监听（`BootReceiver`）。

## 目录结构

```
app/src/main/java/com/clipditto/app/
├── App.kt                        # Application + 通知渠道
├── data/                         # Room 实体 / DAO / 数据库 / 仓库（媒体落盘）
├── service/
│   ├── ClipboardService.kt       # 核心：剪贴板监听 + 悬浮球 + 悬浮面板 + 粘贴
│   ├── PasteAccessibilityService.kt  # 无障碍粘贴
│   ├── ShizukuClipboard.kt       # Shizuku 桥接读取（免打扰）
│   ├── ClipboardShellService.kt  # Shizuku 用户服务（shell 权限）
│   └── BootReceiver.kt           # 开机自启
├── sync/                         # 局域网同步：发现 / 服务端 / 客户端 / 加密 / 设置
│   └── relay/                    # 云端中继同步：WSS 连接 / 端到端加密 / 收发总控
├── share/                        # 文件共享：发现 / 收发 / 落盘（与同步独立）
├── backup/BackupManager.kt       # zip 备份 / 导入
├── ui/
│   ├── MainActivity.kt           # 历史列表、搜索、时间段删除、备份导入、权限引导
│   ├── DevicesActivity.kt        # 局域网设备与同步设置
│   ├── RelaySettingsActivity.kt  # 云端中继设置（服务器/分组/加密/连接状态）
│   ├── FileShareActivity.kt      # 文件共享收发
│   ├── AboutActivity.kt          # 关于页与应用内更新
│   └── HistoryAdapter.kt         # 主界面与悬浮面板共用列表适配器
└── util/                         # 模糊搜索 / 存储统计 / 口令识别 / 更新检查
```
