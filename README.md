# 剪贴板管家（ClipDitto）

仿 Windows 软件 Ditto 的安卓本地剪贴板记录工具。

## 功能

1. **悬浮球**：开启服务后屏幕边缘出现球形悬浮窗（可拖动），单击展开/收起剪贴板记录面板。
2. **自动记录**：复制文字、图片、视频、音频、文件（含截图、录屏文件）自动入库，媒体内容复制到应用私有目录长期保存。
3. **点击粘贴**：光标在输入框中时，点击悬浮面板中的文字记录，自动粘贴到输入框（依赖无障碍服务）；图片/文件/视频则放回系统剪贴板供粘贴。
4. **按时间段删除**：最近 1 小时 / 今天 / 最近 7 天 / 最近 30 天 / 自定义日期范围 / 全部清空，删除时同步清理媒体文件。
5. **备份与导入**：导出为 zip（`clips.json` + 媒体文件），导入时自动合并记录并还原媒体。

## 构建

用 Android Studio（Hedgehog 及以上）打开本目录，等待 Gradle Sync 完成后运行即可。

- AGP 8.5.0 / Kotlin 1.9.24 / Gradle 8.7
- compileSdk 34，minSdk 26
- 数据库：Room（KSP）

## 使用步骤

1. 安装后打开 App，点击「开启监听+悬浮球」，按提示授予**悬浮窗权限**（显示在其他应用上层）。
2. 点击「开启无障碍粘贴」，在系统无障碍设置中找到「剪贴板管家」并开启——这是"点击记录直接粘贴到输入框"的前提。
3. 之后在任何 App 中复制内容都会自动记录；点击悬浮球 → 点击记录 → 内容粘贴到当前输入框。

## 技术要点与已知限制

- **Android 10+ 后台剪贴板限制**：系统不允许后台 App 读剪贴板。本应用采用业界通行方案：检测到剪贴板变化时，临时添加一个 1px 全透明、可获取焦点的悬浮窗，夺取窗口焦点后再读取，读取后立刻移除。需要悬浮窗权限常开。
- **文字粘贴**：先把内容写入系统剪贴板，再由无障碍服务对当前聚焦的可编辑节点执行 `ACTION_PASTE`。未开启无障碍时自动降级为"复制到剪贴板，手动长按粘贴"。
- **媒体粘贴**：通过 `FileProvider` 把私有目录文件以 Uri 形式放回系统剪贴板；目标 App 是否支持粘贴该类型由目标 App 决定。
- **截图/录屏**：系统截图、录屏本质上是图片/视频文件，复制它们（或在文件管理器中复制）即按媒体类型入库。
- 开机自启：授予开机权限后，重启手机自动恢复监听（`BootReceiver`）。

## 目录结构

```
app/src/main/java/com/clipditto/app/
├── App.kt                        # Application + 通知渠道
├── data/                         # Room 实体 / DAO / 数据库 / 仓库（媒体落盘）
├── service/
│   ├── ClipboardService.kt       # 核心：剪贴板监听 + 悬浮球 + 悬浮面板 + 粘贴
│   ├── PasteAccessibilityService.kt  # 无障碍粘贴
│   └── BootReceiver.kt           # 开机自启
├── backup/BackupManager.kt       # zip 备份 / 导入
└── ui/
    ├── MainActivity.kt           # 历史列表、时间段删除、备份导入、权限引导
    └── HistoryAdapter.kt         # 主界面与悬浮面板共用列表适配器
```
